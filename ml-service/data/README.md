# ml-service data files

Committed, offline-usable datasets. Every fact here must stay REAL and
verifiable - re-verify against the cited source before editing, and never
invent numbers, scheme rules or agronomy advice.

| File | What it is | Source / verification |
| --- | --- | --- |
| `Crop_dataset.csv` | 2,200-row public crop recommendation training set (N, P, K, temperature, humidity, ph, rainfall, label). | Public Kaggle/GitHub crop-recommendation dataset; committed copy is canonical (upstream mirror 404s). |
| `disease_symptoms.csv` | Curated disease/pest dataset: 100 rows, 50 diseases across rice, wheat, cotton, tomato, potato, chilli, maize, sugarcane, mustard and gram. Columns: crop, symptoms_text (farmer phrasing, 2 variants per disease), disease, label, severity, treatment, prevention (pipe-separated), source. Trains the symptom classifier (`train.py`) and supplies the treatment/prevention library served by `/disease/diagnose`. | Based on Indian public extension recommendations (TNAU Agritech Portal, ICAR institutes: CICR, CPRI, IIPR, DRMR, SBI, IIWBR, NRRI; PAU packages of practice; PPQS/NIPHM IPM packages). Key actives and doses spot-verified by web search 2026-08-27 (tricyclazole for blast, propiconazole 0.1% for yellow rust, pymetrozine/dinotefuran for BPH, emamectin/spinetoram for fall armyworm, cymoxanil+mancozeb for late blight, metalaxyl+mancozeb for white rust, Trichoderma+carboxin for gram wilt, PBW mating disruption). Per-row citation in the `source` column. |
| `disease_symptoms_sample.csv` | Tiny last-resort fallback so a bare checkout still trains when the curated CSV is absent. Subset of `disease_symptoms.csv`. | Same sources as the curated file. |
| `schemes_catalog.json` | 12 major currently-running Government of India farmer schemes with bilingual (en/hi) name, benefit, structured eligibility, apply steps, official URL. Served by `schemes_catalog.py` when the live myScheme API is unavailable. | Each entry verified against its `source_url` (official portals: pmkisan.gov.in, pmfby.gov.in, pmkusum.mnre.gov.in, soilhealth.dac.gov.in, enam.gov.in, agriinfra.dac.gov.in, pmksy.gov.in, agrimachinery.nic.in, maandhan.in; PIB releases; Budget 2025-26 KCC limit) on the `verified_date` (2026-08-27). e-NAM mandi count updated to 1,500+ (1,522 integrated as of Sept 2025, enam.gov.in). |
| `knowledge_library.json` | 16 bilingual (en/hi) farming-practice articles (soil testing, drip vs flood, IPM, seed treatment, rotation, mulching, composting, safe pesticide use, PM-KISAN enrolment, storage, intercropping, zero-till wheat, SRI, kitchen garden, e-NAM selling, balanced fertilizer). Served by `knowledge_catalog.py`. | Based on the public extension sources in each article's `source_url` (SHC portal, PMKSY-PDMC, PPQS, TNAU, ICAR-IIWBR, Vikaspedia, PM-KISAN and e-NAM portals). Verified 2026-08-27. |
| `market_prices_sample.csv` | Offline fallback served only when the live data.gov.in mandi feed is unreachable. 24 representative rows covering all 8 crops offered by the UI (Wheat, Rice, Potato, Tomato, Onion, Chilli, Cotton, Maize) at real APMC mandis. | Prices are representative values within the modal-price ranges reported by public mandi trackers (commodityonline.com, bankbazaar, krishipulse) for late August 2026: wheat avg ~Rs 2,490-2,540 (Haryana ~3,000), rice ~Rs 3,000-4,500, potato ~Rs 765-900 (cooling), tomato ~Rs 2,070-2,200 (cooling), onion ~Rs 4,040-4,300 (up ~51% YoY), green chilli ~Rs 2,550, cotton ~Rs 6,200-7,500, maize ~Rs 1,600-2,100 (below MSP). Trend flags follow those reported YoY directions. These are fallback samples, not live quotes - the UI's live path always prefers data.gov.in. |
| `weather_forecast_samples.json` | Offline Open-Meteo snapshot for 3 cities used as a weather fallback. | Regenerated by `scripts/bootstrap_datasets.py` from api.open-meteo.com. |

`scripts/validate_catalogs.py` asserts the structural invariants of the three
catalogues (counts, bilingual fields, source URLs) and runs with the standard
library only.
